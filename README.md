# ⚠️ Buggy Quest: Collaborative Mini-Game Challenge

Welcome to **Buggy Quest**, a simple command-line RPG mini-game built in Python. 

A local developer left this project in a broken state! The code doesn't run properly, features are missing, scorekeeping is buggy, and merge conflicts have broken the player menu.

## Challenge Overview
Your team's goal is to:
1. Inspect the code, open issues, and assign team roles.
2. Use **Git branches** and **Pull Requests (PRs)** to fix the bugs safely without breaking main.
3. Document your team's workflow and changes in code comments and PR descriptions.
